> 用法：在原来那个 Claude Design 项目里继续（画布上已有 40 张画板），本文全文作为一条新消息发送。不用重新上传输入包；`00-tokens`、`01`、`02`、`04`、`41` 是本次的上下文，画布上已经有了。

## 0. 要解决的问题

现在设计稿里没有转场规格，只有 `00-tokens` 里两行时长。实现出来的结果是：新建会话、切换会话、重载 agent 时中栏整块瞬间替换，没有过渡；重载 agent 还夹着几百毫秒到数秒的异步等待，这期间界面完全不动，看不出是在换还是卡死。本次把这些补成可以直接写进代码的规格。

## 1. 画板 00：动效小节补这 8 个值

位置：画板 00 右下「图标 · kbd · 动效」栏里，现有三行动效文字的下面继续排，沿用同一种等宽 11 的写法（值 + 名字并排）。**不重排该栏的图标行与 kbd 行，不动画板 00 的其它任何一栏。** 这一栏排不下就把画板 00 的高度从 924 往下加，加到够为止。

| 名字 | 值 | 用在哪 |
|---|---|---|
| `motion.ease` | `cubic-bezier(.215,.61,.355,1)` | 全套动效唯一的曲线，所有时长都配它 |
| `motion.fast` | 120ms | （已有，值不变）hover 进出、颜色、等待态变暗 |
| `motion.base` | 160ms | （已有，值不变）展开折叠、弹层出现 |
| `motion.transition` | 200ms | 内容整块替换的入场 |
| `motion.rise` | 8px | 内容整块替换入场时的上移距离 |
| `motion.pop` | 4px | 弹层出现时的位移距离 |
| `motion.stagger` | 40ms | 成组元素入场的错开步长，最多错开 3 个元素 |
| `opacity.pending` | 0.5 | 等待期内容的减弱不透明度 |

现有那行「motion.fast 120ms ease-out（hover / 颜色）」里的 `ease-out` 字样改成 `motion.ease`，`motion.base` 那行同样改。**画板 05 里不得出现这张表以外的数值**——我们这边的约定是 `tokens.dart` 只从 `00-tokens` 提炼，不从页面画板反推。

## 2. 新增画板 05 `05-motion`「转场规格」

### 2.1 画板规格

- 文件名 `05-motion.dc.html`，标题「转场规格」。
- 放 **P1 页**，坐标 `x=3040, y=2096`，frame **1440×1200**。排不下往下加高，**不改宽度**。
- 编号只增不改：05 之前未用过，不要动 00–04。

### 2.2 每组的统一排法

画板里有四个规格组（A / B / C / D），A、B、D 各按下面四件套排，C 只有一行字：

1. **横向分帧**：按各组给定的帧数与时间点画，每帧只画受影响的区域（不必画整窗），缩到宽约 440–480 的比例；每帧上方标真实时间点。
2. **规格表**（等宽 11，紧接分帧下方）：逐行「属性 · 起 → 止 · 时长 · 曲线 · 延迟」，本文已经把每行写好，照抄进表。
3. **时间轴带**：一条横轴标出各段的起止。
4. **反例行**：本文每组末尾给了原话，**原样抄进画板**，这行我们当验收项用。

### 2.3 A 组 · 会话内容整块替换

**触发**：侧栏点另一条会话；或线程头 `+` 选 agent 后新会话建好（弹层见画板 41）。两者视觉上是同一件事，只画一遍。

**受影响的只有两处**：线程头的标题文字、转录区。两处走**同一条时间线**，同起同止。

**分帧**：3 帧，`t=0ms` / `t=100ms` / `t=200ms`。

**规格表内容**（照抄）：

- 旧内容 · 可见 → 移除 · 0ms · — · 无延迟（**不做淡出，触发瞬间直接消失**）
- 新内容 opacity · 0 → 1 · `motion.transition` 200ms · `motion.ease` · 无延迟
- 新内容 translateY · `motion.rise` 8px → 0 · `motion.transition` 200ms · `motion.ease` · 无延迟
- 线程头标题 · 同上两行 · 与转录区同起同止
- 线程头的四个图标按钮 · **不动**
- 输入框 · **不动**
- 左侧栏 · **不动**
- 右栏 · **不动**
- 顶栏（项目名 / 分支 / 窗口控制）· **不动**

**错开规则**（照抄）：

- 落到**新建会话空态**（画板 01 的居中 agent 图标 / 标题 / 提示行）时，这三层错开入场，步长 `motion.stagger` 40ms，顺序自上而下：图标 0ms、标题 40ms、提示行 80ms。
- 落到**已有转录**时，整个转录区**作为一个整体**入场，**不逐卡错开**。

**反例行**（照抄）：不做旧内容淡出，不做横向滑动，不做缩放，不做 opacity 以外的滤镜，新旧内容任何一帧都不得同时可读，长转录不得逐卡错开。

### 2.4 B 组 · 重载 agent（带等待期的替换）

**触发**：线程头上的 reload 图标（画板 01 / 41 里那个）。

**分帧**：4 帧 —— `t=0ms（点击瞬间）` / `t=120ms（等待中）` / `完成 t=0ms` / `完成 t=200ms`。

**规格表内容**（照抄）：

阶段 ① 点击 → 进入等待

- 线程头 spinner · 无 → 出现 · 0ms · — · 无延迟（**复用画板 02 / 31 那个 accent 1.5px 弧，不新画**）
- 转录区 opacity · 1 → `opacity.pending` 0.5 · `motion.fast` 120ms · `motion.ease` · 无延迟
- 转录区交互 · 启用 → 禁用（不响应点击，悬浮不出容器）· 0ms
- 输入框 / 左侧栏 / 右栏 / 顶栏 · **不动，不变暗**

阶段 ② 等待中（时长不可预知，几百毫秒到数秒）

- 保持阶段 ① 的终态：转录区停在 0.5、spinner 持续转
- **不加任何新元素**：无骨架屏、无进度条、无遮罩、无 toast、无百分比、无「正在重载…」文案

阶段 ③ 完成

- 线程头 spinner · 出现 → 无 · 0ms
- 转录区 · **整套复用 A 组的入场**：旧内容瞬间移除，新内容 opacity **0 → 1**（起点是 0，不是 0.5）+ translateY 8px → 0，`motion.transition` 200ms，`motion.ease`

阶段 ③' 失败（重载没成功）

- 转录区 opacity · 0.5 → 1 · `motion.fast` 120ms · `motion.ease`
- 不做入场动画，错误走画板 34 的状态条，样式不动

**反例行**（照抄）：等待期不得新增任何组件，不得做进度表达，不得让输入框或左右栏跟着变暗，完成后的入场不得从 0.5 起。

### 2.5 C 组 · 右栏标签切换（设置 / 文件 / Agents / 终端）

**不画分帧**，在画板上写这一行（照抄）：

> C · 右栏标签切换：完全复用 A 组入场规格（新内容 opacity 0 → 1 + translateY 8px → 0，`motion.transition` 200ms，`motion.ease`；旧内容瞬间移除）。替换区域 = 右栏标签栏以下的内容区；右栏标签栏本身、分隔线、栏宽都不动。

### 2.6 D 组 · 弹层出现与关闭

覆盖画板 40 / 41 / 42 里所有弹层与菜单。**弹层本身的样式一概不动**，只定出场。

**分帧**：3 帧，`t=0ms` / `t=80ms` / `t=160ms`，画向下弹的那种（例：线程头 `+` 的新建会话弹层，画板 41）。

**规格表内容**（照抄）：

- 弹层 opacity · 0 → 1 · `motion.base` 160ms · `motion.ease` · 无延迟
- 弹层 translateY · 向下弹时 `-motion.pop` −4px → 0；向上弹时 `+motion.pop` +4px → 0 · `motion.base` 160ms · `motion.ease` · 无延迟
- 阴影 · 与弹层同一条时间线，不单独设
- 缩放 · **不做**
- 触发按钮的选中容器 · 0ms 立即出现，不等弹层
- 关闭 · **不做动画，立即消失（0ms）**

在分帧旁边写一行（照抄）：向上弹的弹层（`@` / `/` 菜单、模型与思考强度选择器、用量弹层）方向取反，位移 +4px → 0，其余完全相同，不另画。

**反例行**（照抄）：不做缩放，不做从触发点放大的效果，关闭不做退场动画，弹层出现期间底层内容不变暗、不模糊。

### 2.7 轻量交互规格块

画板底部一个纯文字块（等宽 11，不画分帧），照抄：

- hover 进入 / 离开：容器底色与其中的文字、图标颜色走同一条 `motion.fast` 120ms / `motion.ease`，进出同时长。
- active（按下）：**不做过渡**，立即换到按下叠色；松开回 hover 态走 `motion.fast` 120ms。
- 焦点环：**不做过渡**，立即出现、立即消失。
- 展开 / 折叠（工具卡、思考块、计划卡、diff 卡）：高度与 opacity 走 `motion.base` 160ms / `motion.ease`，同起同止。

## 3. 不要动

- 除画板 00 的动效小节（按 § 1）外，**不改任何现有画板**的布局、间距、字体、颜色、文案。
- 除 05 外**不新增画板**，不改已有编号与文件名。
- **不设计转录区流式内容的出现动效**——新工具卡 / 文本块逐步追加、spinner 转速、`Thinking...` 的呼吸，本次不碰。
- 不做可播放的动画演示区，画板 05 是纯静态规格图。
- 不引入弹跳（overshoot / spring / 回弹）。
- 不引入本文表格以外的时长、位移、曲线、透明度值。
- 不引入整页级转场：左右滑动、翻页、缩放、3D。
- 不设计加载骨架屏。
