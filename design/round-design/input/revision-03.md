# AcpAgent Client 设计稿修订 03 · 会话时间线弹层

> 用法：在原来那个 Claude Design 项目里继续（画布上已有 42 张画板），本文全文作为一条新消息发送。不用重新上传输入包；`00-tokens`、`01`、`02`、`03`、`05`、`11`、`41`、`42` 是本次的上下文，画布上已经有了。
> 本次**只做两件事**：给画板 01 / 02 / 03 的线程头补一个按钮，新增一张画板 43。其余画板一律不重绘。
> 本文里的数值、行为、方向全部是定好的，**照着画，不要替换方案、不要加备选、不要留待定**。哪一条你认为不可行，停下写成画布便签交回，不要自行改成别的做法。

## 0. 要解决的问题

一条会话跑到几十轮之后，转录区只能靠滚轮翻，找不到「第 7 轮问的那句」在哪。本次加一个**会话时间线**：线程头上一个按钮，点开一个弹层，按轮列出每一轮用户问了什么、agent 最后答了什么（各取首行），点一行转录区就滚到那里。

参照物是 pi 桌面版右侧的会话树：用户消息按 `01` `02` … 编号，agent 回复一律标 `A`，两者都只显示首行；被打断、没有回复的那一轮只有编号行没有 `A` 行。**只取它的信息结构，视觉按本项目的风格系统重做**（§ 2 风格系统见 `design-prompt.md`，不重复）。

画板 01 / 02 / 03 **只改这一个按钮**，其它任何像素不动。按钮的三态与弹层本体都画在画板 43 里，这三张只画默认态。

## 2. 新增画板 43 `43-session-timeline`「会话时间线弹层」

### 2.1 画板规格

- 文件名 `43-session-timeline.dc.html`，标题「会话时间线弹层」，头部说明行写「协议来源：session/prompt（轮边界）· user_message_chunk · agent_message_chunk」。
- 放 **P3 页**（弹层与菜单），坐标 `x=3840, y=0`，frame **1200×900**。排不下往下加高，不改宽度。
- 编号只增不改：43 之前未用过；40 / 41 / 42 不动。

### 2.2 弹层几何与外观

| 项 | 值 |
|---|---|
| 锚定 | 线程头 history 按钮的**正下方**，间隙 `popover.below` 4px；**弹层右边缘对齐按钮右边缘**（按钮贴中栏右侧，向左展开才落得进窗口） |
| 宽度 | 420（= 画板 42 `@` / `/` 菜单那一档 `menu.width.inline`） |
| 最大高度 | **主窗口高度的 75%**（含内边距与标题行）。内容不足时按内容收窄；超过时**内容区内部滚动**，标题行钉在滚动区之外——与画板 40 / 41 / 42 弹层封顶滚动的做法一致 |
| 容器 | 与 40 / 41 / 42 同一套：`surface.popover` 底 + 1px `border.subtle` + `radius.6` + `shadow.popover`，内边距 4 |
| 标题行 | 沿用 42 的分组标题样式（高 22、11 / 500 / letter-spacing .06em / #8b8b96），文案 **`Session timeline · 5 turns`**（数字 = 轮数，等宽数字） |
| 滚动条 | 不画可见滚动条（与 42 一致） |
| 出场 | 画板 05 D 组：opacity 0 → 1 + translateY −4px → 0，`motion.base` 160ms，`motion.ease`；关闭 0ms；按钮的选中容器 0ms 立即出现 |

### 2.3 行：时间轴样式

弹层内容区是一列**行**，每轮两行：先一行用户 query，再一行 agent 回答（`A`）。行的构成从左到右四列：

| 列 | 宽 | 内容 |
|---|---|---|
| 导轨列 | 16 | 一条 1px `border.subtle` 竖线居中贯穿整列（`x=8`），每行在线上一个**节点**：用户行是 6px 实心圆（#8b8b96），`A` 行是 6px 空心圆（1px #8b8b96 描边、`surface.popover` 填充）。竖线从第一个节点中心画到最后一个节点中心，两端不出头 |
| 标签列 | 24 | 等宽 11、等宽数字、左对齐：用户行是两位编号 `01` `02` …（从 **01** 起，满 100 轮自然变三位），颜色 `text.secondary`（#62626e）；`A` 行固定一个字母 **`A`**，颜色 #8b8b96 |
| 间隙 | 8 | — |
| 文字列 | 余量 | 单行、超出省略号。用户行 13 / 500 / #33333d；`A` 行 12 / 400 / #62626e（同 42 里命令描述那档） |

- 行高 28（`control.standard`），行内边距 0 8，圆角 `radius.4`。同一轮的两行紧挨；轮与轮之间空 4（`space.4`），导轨竖线跨过这个空隙不断。
- **悬浮**：标签列 + 文字列之上出 6% 深色容器（rgba(30,30,38,.06)，`radius.4`）；导轨列不在容器里。
- **键盘高亮**：与 42 一致——上下键移动高亮，高亮行用按下态容器（rgba(30,30,38,.10)），高亮移出视口时自动露出；Enter = 点击。**打开那一下没有高亮。**
- **打开时滚到底部**：最新一轮在视口内。
- **没有 `A` 行的轮**：该轮到目前为止没有任何 agent 文本（被取消、失败、或正在跑还没出字），只画编号行，导轨上只有一个节点。**不加 spinner、不加占位文案**——运行中已由线程头 spinner 表达。
- **首行怎么取**（写在画板注释里，实现照它做）：用户行取消息第一个非空行，`@` 提及写成 `@name` 纯文本（不画芯片），只有图片没有文字的消息写 `image`；`A` 行取该轮**最后一条** agent 文本（工具调用之间的中间文本不算）的第一个非空行，去掉行首的 Markdown 标记（`#`、`-`、`1.`、`>`、代码围栏），去完是空的再往下取一行。

### 2.4 交互

| 动作 | 结果 |
|---|---|
| 点 history 按钮 | 开弹层；**再点一次关**（切换） |
| Esc | 关 |
| 点弹层之外任何地方（含转录区、输入框、侧栏） | 关；那一下点击不再触发别的动作 |
| 点一行 / 高亮行按 Enter | 转录区**立即**（0ms，不做滚动动画）滚到该条：目标块**顶边对齐转录区顶部内边距**（16）；用户行落地后气泡进入画板 11 的「点击聚焦」态（焦点环，再点别处退出，规则同 11）；`A` 行落地不加任何高亮。弹层随即关闭（0ms）。转录的「跟着底部走」停掉，与用户自己翻上去同语义 |
| 空态（有会话、还没有任何一轮） | 弹层只剩标题行 `Session timeline · 0 turns` + 一行占位文案 **`No messages in this session yet`**（12 / #8b8b96，行高 28，无导轨、无节点），弹层按内容收窄 |

### 2.5 画板里要画的样张（横向并排，每张上方小标题写状态名）

1. **线程头局部 · 三态**：只画线程头右侧五个按钮那一段（宽约 200），三份并排：默认 / 悬浮 + 提示条 `Session timeline` / 打开态（选中容器 + accent 图标）。
2. **弹层 · 完整样张**：挂在打开态按钮下方，右对齐，5 轮示例数据（照抄，含标点；第 03 轮故意没有 `A` 行）：

   ```
   01  hi
   A   你好！有什么可以帮你的？
   02  你是什么模型
   A   当前会话跑的是 deepseek-v4-flash（provider: deepseek），思考强度 high
   03  你能看到这张图吗
   04  你能看到这张图吗
   A   能看到。这是 Pi Agent 桌面版的截图，里面有：
   05  当前 会话的jsonl保存在哪里
   A   当前会话的 JSONL：
   ```

   标题行 `Session timeline · 5 turns`。第 02 轮的 `A` 行要长到被省略号截掉，用来示范单行截断。
3. **行的四态**：从样张里抽四行放大并排：默认 / 悬浮容器 / 键盘高亮容器 / 没有 `A` 行的轮（编号行 + 导轨上单节点）。
4. **封顶滚动**：30 轮的长列表，弹层高度 = 900 × 0.75 = 675（在这张画板里按 frame 高 900 算），标题行钉住，内容区从中间截断示意内部滚动，视口停在底部（第 30 轮可见），无可见滚动条。
5. **空态**：`Session timeline · 0 turns` + `No messages in this session yet`。
6. **跳转落点**：转录区局部（宽 800，高约 240）：目标用户气泡顶边贴转录区顶部 16px 内边距、气泡处于画板 11 聚焦态，其下接着那一轮的助手正文。

### 2.6 规格表与 token 表（画板底部）

- **规格表**（等宽 11，照 § 2.2 / § 2.3 / § 2.4 抄成三张表），实现直接按表写。
- **本画板新增 token**（与画板 06 同一种表：token / 值 / 用途；画板 00 不改，这组值只服务画板 43，实现回写 `tokens.dart`）：

| token | 值 | 用途 |
|---|---|---|
| `timeline.maxHeight` | 主窗口高 × 0.75 | 弹层总高上限（含内边距与标题行） |
| `timeline.width` | 420 | 弹层宽（= `menu.width.inline`，登记别名） |
| `timeline.rail` | 1px · `border.subtle` | 导轨竖线 |
| `timeline.railColumn` | 16px | 导轨列宽，线居中 |
| `timeline.node` | 6px · #8b8b96 | 节点直径与颜色（用户实心、`A` 空心 1px） |
| `timeline.label` | 24px | 标签列宽 |
| `timeline.turnGap` | 4px | 轮与轮之间的空隙 |

其余（行高、圆角、容器叠色、字阶、阴影、动效）全部复用 00 已有的值，画板里不得出现这张表与 00 之外的数值。
