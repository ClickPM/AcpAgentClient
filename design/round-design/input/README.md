# 交给 Claude Design 的输入包

这个目录整个交给 Claude Design，是 round-design 设计轮的全部输入；仓库内部的原料与审核清单在上一层的 `../materials.md`，不用给设计工具。

## 用法

1. 新建 Claude Design 项目，把本目录的**全部文件**作为附件上传（含子目录）。
2. 把 `design-prompt.md` 的全文作为第一条消息粘贴发送。
3. 按简报 § 5 的画布分页顺序出稿：P1 → P2 → P3 → P4，可分多次；每页完成后逐画板导出 PNG。
4. 把画布链接交回仓库这边审核（审核清单在 `../materials.md` § 5）。

## 文件清单

| 文件 | 是什么 | Claude Design 怎么用 |
|---|---|---|
| `design-prompt.md` | 设计简报：风格系统、结构来源、黑名单、40 张画板清单、产出要求 | 首条消息全文粘贴 |
| `canvas.json` | 40 张画板的布局清单：文件名、标题、四个分页、坐标与 frame 尺寸 | 直接作为画布布局；只改坐标与高度，不改文件名与编号 |
| `prototype/index.html` | 界面骨架原型，交互与信息层级的唯一来源 | 结构照它画，视觉重做；里面的演示工具条按简报 § 4 剔除 |
| `prototype/mockplus-default-view.png` | 壳的截图：右栏折叠 | 三栏比例参照 |
| `prototype/mockplus-expanded-view.png` | 壳的截图：右栏展开 | 同上 |
| `reference/interactions-22.md` | 转录区 22 种卡片的逐项交互说明与协议来源 | 画 P2 各卡时按它定状态与字段 |
| `reference/acp-projection.md` | ACP 可投影内容的完整清单（字段名、枚举值、状态名） | 画 27 / 29 / 31 / 32 / 34 / 40 / 80 时按它取名字，不自造 |

## 约束提醒

- 画板编号与文件名一经使用不得改动；觉得缺画板或缺功能，写成画布便签交回，不直接加。
- 简报 § 4 列出的原型演示入口在任何画板都不得出现。
- 所有数值来自 `00-tokens` 画板；先出 P1 再出其余页。
