B · 分组判定、流转与数据持久化规格（Lifecycle & Persistence Rules）
维度 / 场景
判定条件与数据源
UI 表现与交互契约
ACTIVE 区（最高优先级）
attached == true
所有当前挂载在活跃 Agent 连接上的会话（含运行中、等待授权、普通挂载）。即使该会话带有 isPinned 标记，只要处于活跃连接中，一律归入 ACTIVE 区展示，保持实时状态和连接绿点统一。
PINNED 区（非活跃置顶）
attached == false && isPinned
本地会话未连接（detached / unattachable / 挂起）且被打上置顶标记。独立分组聚类展示，按 pinnedAt 或 updatedAt 降序排序，数量胶囊使用 Accent 样式。
HISTORY 区（普通归档）
attached == false && !isPinned
未连接且未置顶的常规历史会话。支持整体折叠，按时间戳降序排布。
Pin / Unpin 公共切换按钮
AcpIcons.pin (切换持久化)
悬浮快捷操作栏第一位。未置顶态为描边图钉（tooltip `Pin session`）；已置顶态为实心/高亮图钉（tooltip `Unpin session`）。点击立即翻转 isPinned 状态并写回本地 sessions.json。
Pinned ↔ Active 平滑迁移
onSelect / onSuspend
点选 Pinned 会话触发加载连接，连接成功后条目平滑升入 ACTIVE 区；在 ACTIVE 区挂起或断开连接时，若原带有 isPinned 标记，则平滑降格回 PINNED 区，而不是落入普通 History。
首 Query 悬浮卡片机制
session.firstPrompt 投影
鼠标悬浮任意会话行停留 150ms 触发 OverlayPortal 飞出卡片。展示首个用户 prompt 原始文本（多行折行、最大 4 行），右侧对齐不遮挡行内操作按钮，鼠标穿透点击。
