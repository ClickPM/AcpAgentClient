口径与行为
问题
裁定
什么算「在跑」
该会话有在途 prompt（含等待授权 / 等待追问），与画板 06 的运行中判定完全一致
数谁
按会话计数，不按 agent 进程；一个工作区里 3 条会话在跑就是 3
触发钮的数字
所有工作区合计（含当前）；为 0 时整个徽标不渲染
排序
不因有在跑会话置顶或重排，仍是 This Window / Recent 分组内的原顺序
徽标挂在哪一行
本次运行里打开过、内存里还有在跑会话的工作区都挂，不分 This Window 还是 Recent Projects。这不是后台探活：换工作区只是把当前会话放下，它的 agent 连接还在本进程里活着，在跑与否我们本来就知道。本次运行从没打开过的工作区恒无徽标
重启之后
应用重启后没有任何 agent 连接，所有徽标从零开始，不从磁盘恢复在跑状态
刷新
由会话运行态变化驱动即时更新；不轮询、不做过渡动画（数字直切）
与侧栏的分工
侧栏扫掠线回答「这个工作区里哪条在跑」；本徽标回答「别处还有多少在跑」，两者不互相替代，也不在切换器里放扫掠线
