B · 分组判定与状态流转规格（Protocol & Lifecycle Rules）
维度 / 场景
判定条件与数据源
UI 表现与交互行为
Active 区（已连接）
SessionAttach.attached
当前已挂载在存活 Agent 连接上的会话（含新建 session/new、已载入 session/load、后台运行中会话）。图标右下角带 6px 在线绿点，副标题追加「· 已连接」。
History 区（历史会话）
detached / unattachable
本地索引 sessions.json 中未挂载到当前连接的归档会话。图标 opacity 0.75、无在线绿点；按 updatedAt 降序排列，分区支持整体折叠/展开。
History → Active 升格
onSelect → ensureLoaded
点击 History 中的会话触发 agent_connect + session/load（或 resume），挂载成功后条目平滑升入 Active 区并置为选中态。
Active → History 降格
session/close / 进程断开
点该行悬浮动作里的「挂起」（见下一行）、重载 Agent 连接或子进程退出时，原 attached 会话解除挂载，自动沉降回 History 区并按时间戳归位。
挂起（Active 行内动作）
AcpIcons.pause → session/close
Active 行悬浮动作里的第一枚图标（在改名 / 删除之前），tooltip `Suspend session`：点击把这条会话交还 agent（session/close = 先 cancel 再释放，不删记录），本地转录留着只读，条目随即按上一条降格回 History；再点它那一行走「History → Active 升格」挂回来。仅当该行会话所属 agent 同时声明了 sessionCapabilities.close 与 loadSession（或 resume）时渲染，否则这一行仍只有改名 / 删除两枚。
