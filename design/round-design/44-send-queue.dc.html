交互 / 场景 触发方式 状态迁移与行为规范
回合中追加消息 输入框非空 + Enter ↵ 立即锁定当前输入框的 ContentBlock 列表（文字 + 附件芯片）入队尾，输入框清空，线上不发第二个 session/prompt。
Fast-track 插队 输入框为空 + Enter ↵ 或点 Send Now 状态转入 AbsorbingCancel：先发 session/cancel，吞掉在途回合的结束事件后立即发出目标条目。
回退编辑 输入框为空 + ↑ 或点编辑图标 从队列移除该条并挪回主输入框（主输入框已有文字时以空行拼在后面，附件芯片一并还原）；不做行内编辑。
错误 / 停止保护 回合报错返回 / 手动点停止 状态转入 Paused：不自动出队，防止错误级联放大；用户点击「恢复出队」或再次主动发送/入队时恢复 AutoProcess。
会话归属与清理 切换会话 / 断开 / 关闭 每个会话独立维护内存队列：切走会话时后台回合结束照常自动出队；agent 断开、会话关闭或删除时清空该会话队列，重启不持久化。
只用 ACP 标准 session/prompt 与 session/cancel，不接任何 _session/steering 私有扩展；投影层（lib/projection/）与 Rust 桥零改动。
