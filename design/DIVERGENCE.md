# 画板与实现的偏离清单

> 本文记录**实现与画板不一致的地方**，一条一行，说明画板画的是什么、实现是什么、为什么、以哪边为准。
> 这些条目**不要求补设计稿**（所有者裁定 2026-09-20）：它们从 `rounds/BACKLOG.md` 移到这里，由「待办」改成「记录」。
> 画板清单与计数仍以 [`README.md`](README.md) 为准；本文只在它之上加一层「这张画板哪里已经不作数了」的注记。

## 怎么用

- **看画板之前先看本文**。画板 PNG 是验收基准（CLAUDE.md 规则 3），但下面列到的那几处已经不是——以「实现是什么」那一栏为准。
- **新增偏离时追加一行**，不回头改画板。格式：画板编号 · 画板画的是什么 → 实现是什么（为什么）·（轮次, 日期）。
- **不是所有偏离都可以随手加**。规则 3 的顺序「先改设计稿、再进轮次」照旧管**扩功能边界**；本文收的是已经发生的三类既成事实：实现先行（A）、画板画错（B）、实现有意少做（C）。要新长出一块设计稿上没有的功能，仍然走裁定。
- 下个设计轮**如果**决定回补某几张，补完就把对应行从本文删掉，并在 `README.md` 的「变更记录」里记一句。

## A · 实现已超越画板（画板没有，实现先做了）

画板上压根没画这些，实现按所有者当场裁定先做了。**画板缺的这块以实现为准。**

1. **Thread → Session 文案收敛**：画板 00 的 `New Thread` 字样、画板 01 / 02 / 03 / 06 / 31 / 50 / 60 / 61 的 `New <agent> Thread` 标题、画板 40 `+` 弹层的 `Threads` 行 → 实现统一为 `Session`（中文「会话」）。理由是协议层与状态层本就是 `session/*`，只有早期临摹 Zed 原型留下这几处英文。**不在收敛范围**：Zed 上游的 `ThreadEvent` / `ThreadStore` / `threads.db` / `acp_thread.rs` 照旧。（main 直改, 2026-09-20）
2. **深色主题的切换按钮与深色整屏**：画板 07 是规格表，**切换按钮本身没画**；实现按所有者指图放在侧栏标题条右端（ghost 图标按钮 24 见方，浅色出月亮、深色出太阳，tooltip `Switch to dark/light mode`），月亮与太阳两个图标按其余图标的路子画的 24 视口单线。画板 07 自己写明的三张深色页面画板 **90 工作台整屏 / 91 转录卡片合集 / 92 弹层与叠色**也不存在，深色只逐 token 对过表，**没有整屏验收基准**。（2026-09-20）
3. **外来 SVG 在深色下的取色**：画板 07 没写 registry 的 `icon.svg` 与内置条目随包带的那两张深色下取什么色 → 实现定为 `Neutral.strong`（浅色 `n.strong` ↔ 深色 `d.strong`，与应用标记同一档），落在 `tokens.dart` 的 `SvgTint.mark`。（2026-09-20）
4. **画板 70 的「外观」小节**：画板没有这一小节 → 实现是四行下拉（界面西文 / 界面中文 / 代码等宽西文 / 代码等宽中文），每行「标签 + 当前值 + 下拉按钮」；本机没有该字体时该行 muted 并多一个「去下载」按钮。（R7.6, 2026-09-20）
5. **画板 01 中间的大图标位**：画板画的是占位菱形 → 实现改成「有 `icon.svg` 就画各 agent 自己的 logo」（与画板 41「agent 图标位是单色占位，实现里换各 agent 自己的 logo」同口径）。（2026-09-18）
6. **输入框的图片粘贴与附件区**：画板 01–03 / 40 都没画 → 实现加了 Ctrl/Cmd+V 粘贴图片、输入行之上的附件芯片条与悬浮预览（对齐 Zed 的交互，`docs/design.md` § 9 已记）。（2026-09-18）
7. **画板 31 的「没走到结束值」一态**：画板只画了五种协议 `stopReason` 的结束行 → 实现多一档「失败」徽章（error 色）+ 错误原文，允许折行到 3 行。起因是 dsh 回 `-32602` / `-32603` 时界面上只有一个 `?` 徽章加一个耗时，用户看不出发生了什么。（2026-09-18）
8. **画板 40 / 41 / 42 弹层的「条目多到出屏」一态**：三张都按「条目有几行就多高」画的 → 实现给内容区封顶 `Geometry.menuMaxHeight`（320）并在内部滚动，键盘上下键把高亮移出视口时自动露出，搜索框钉在滚动区之外。起因是模型列表长到 20+ 时弹层顶出窗口、下面的条目既看不见也选不中。（2026-09-18）
9. **画板 05 B 组的第二个触发**：B 组「带等待期的替换」只写了会话头的 reload 图标 → 实现把**新建会话**（会话头 `+` 选 agent、`send()` 现开一条）也接进同一套（`reloading` 改名 `waitingForAgent`，转录降到 `opacity.pending` 且不可交互 + 会话头那只 spinner，不新增元素）。（2026-09-18）
10. **壳上 14 个入口的悬停提示**：画板 00 没有 tooltip 这一组 token、画板 01–04 / 40 也没画提示条这一态 → 实现加了（`lib/ui/shell/tooltip.dart`；底色 / 边框 / 圆角 / 字样借弹层与 secondary 那几档，出现延迟 `motion.fast × 4`，几何值收在 `Geometry.tooltip*`）。（2026-09-18）
11. **画板 40 的会话配置渲染**：画板画成「模型 / 思考强度 / 模式三个固定下拉 + 未知分类一个面板 + boolean 一个面板」→ 实现改成**固定档序平铺**（`mode → model → model_config → thought_level → 其余`，档内保持数组顺序，一条 configOption 一格，boolean 就地开关）。依据是实测五个 agent 里四个在旧渲染下丢格（dsh 的 `permission`、codex 的 `collaboration_mode`、claude 的 `agent` 与 `fast`、cursor 的 `fast`）。**gallery 的 `boardComposerOptions`（`lib/gallery/boards/board_helpers.dart`） 仍按 PNG 的三格口径渲染，与真输入框不同**。（2026-09-18）
12. **画板 25 的快捷键标签与范围下拉**：画板在三个按钮上画了 `Kbd` 标签（Allow `Alt-Shift-A` / Deny `Alt-Shift-X` / 范围下拉 `Ctrl-Alt-A`），全应用没有任何对应的按键处理 → 实现去掉标签、按钮按内容收窄，不做快捷键；同时把范围下拉从卡片自己的 `Stack` 改成走 `PopoverAnchor` 浮在 Overlay 上（之前转录里下一张卡绘制顺序更晚，会把展开的菜单压住）。（2026-09-18）

13. **画板 01 侧栏顶部的标记**：画板画的是临时标记 → 实现换成 `design/brand/` 里的正式应用标记（`lib/ui/shell/app_logo.dart` 按同一几何拼，所有者裁定 2026-09-17）。（2026-09-17）
14. **画板 04 的会话删除图标**：画板按 `sessionCapabilities.delete` 裁剪 → 实现改成一律显示（agent 没声明 delete 时也能删本地那条记录）。（2026-09-18）

15. **画板 08 的三处偏离，待所有者确认**（board-08，2026-09-22）：① **权限卡与 elicitation 卡不折叠** —— 画板的「折叠范围与例外」两列都没列到它们，实现按「不折叠」处理（挂起的那张必须看得见，已回应的那张是「授权过什么」的记录）；② **项目触发钮的 tooltip** 在有徽标时整句换成「N 个会话在运行 · M 个工作区」，没徽标时仍是 `Recent workspace` —— 画板要的是给徽标单独挂一条，但 `AcpTooltip` 是 `MouseRegion`，套两层会两条一起弹；③ 切换器里当前工作区那一行的**对勾在右侧**（画板 41 定的位置，徽标排它左边），而画板 08 把对勾画在路径左侧 —— 本次「行高、缩进、分隔线都不动」，所以沿用 41 (2026-09-22)

16. **画板 08 没画「重放回来的历史怎么折」**（iteration, 2026-09-22）：画板 08 的折叠规则通篇按「回合」写，而回合边界（`TurnEntry`）只有我们自己 `session/prompt` 时才放，`session/load` 重放回来的历史一条都没有（R6 裁定，`docs/design.md` § 3）——照画板实现的结果是重开应用后整份历史都不折（所有者报障 2026-09-22）。实现给切轮加了一条退路：**没有轮边界时按顶层用户消息切轮**（`isTurnStart`，与画板 43 会话时间线、Restore 截断点同一口径），历史因此照样折。代价是历史轮拿不到 `TurnEntry`：摘要行第二行的**模型名没有**（退化成画板已经画了的单行态）、**回合页脚不出**（耗时与用量都在 `PromptResponse` 里，重放不带回来）。

29. **输入框粘贴复制的文件与目录**：画板 01–03 / 40 / 42 都没画 → 实现在 Ctrl/Cmd+V 时把资源管理器里复制的文件与目录**默认按路径**加成 `resource_link`（正文里一个 `@名字`，与画板 42 `@` 菜单挑中的是同一个形状，没有新元素）；agent 收图时图片文件照旧成芯片（第 6 条），空的与超 20 MB 的图片文件也退回路径。起因是项目外的文件与目录没有别的路加得进来（`+` → Files & Directories 同日改走画板 42 的 `@` 菜单，只列项目内）。（iteration-03, 2026-09-23）

33. **发送前把会话挂回来（画板 05 B 组第三个触发、画板 31 失败态的第二个来源、画板 01 / 40 输入框的一句占位文案）**：画板都没画「会话没挂在 agent 当前那条连接上」这回事 → 实现（iteration-07，BACKLOG P0「会话身份与生命周期」）：① 发送前要先挂回（连上 → `session/load` / `session/resume`）时套用 B 组同一套等待期（第 9 条的 `waitingForAgent`，不新增元素）；② 挂不回的那一轮照第 7 条的「失败」结束行收在转录里（用户消息 + 原因），不再另开一条会话把选中的顶掉；③ 能力已知且挂不回的会话（agent 既没有 `loadSession` 也没有 `resume`），输入框占位文案换成「这条会话在当前连接上无法继续，发送会新开一条」——与既有的「先选一个项目目录，新会话的 cwd 从它来」同一个出口。（iteration-07, 2026-09-23）

19. **画板 51 / 52 的认证文案**：画板 51「需要认证」条目的描述写死「ChatGPT 登录」、画板 52 的方法名（Sign in with ChatGPT / Codex CLI）是 codex 专属样例 → 规则 2 不按 agent 特判，实现显示「需要先完成认证」、方法按 `authMethods` 原名列出。（R5, 2026-09-16）
20. **画板 50 与 51 对不上**：画板 50 的未安装行没有分发方式芯片、画板 51 的未安装卡有 → 实现统一按 51。（R5, 2026-09-16）
21. **画板 70 头注自相矛盾**：头注写「registry 型只读」但每行都有「编辑」键 → 实现里 registry 型点「编辑」是只读展开拉起参数。（R5, 2026-09-16）
30. **画板 53 的 binary 升级说明行**：画板底部注记写 binary 升级「下面加同一行『仍可正常使用』小字」，那一行是「v0.76.0 仍可正常使用；新版本握手通过后才切换」→ 实现对 binary 写「新版本解压完成后才切换」（binary 的安装与升级都不做首次握手，照写就是在说一件没发生的事；npx 那一行照画板）。（board-53, 2026-09-23）
31. **画板 07 § 2.9 终端 ANSI 的白 / 亮白**：画板定「黑白 = `n.strong` / `n.canvas`」、亮白复用同色，即白 = 背景色 → 实现取白 = `n.text`、亮白 = `n.strong`（深色跟着换套），即「正文 / 强调前景」，与 Windows 控制台「Gray 是默认前景」的语义一致。shell 大量拿 37 / 97 当普通字色：PSReadLine（pwsh 7 与 Windows PowerShell 5.1 都一样）的参数、成员、类型是 `ESC[37m`，数字是 `ESC[97m`，照画板取值就是终端里空格之后打的字全都看不见（所有者报障 2026-09-23）。代价：拿 47 当底色的组合（PSReadLine 选区 `ESC[30;47m`）在浅色下是深墨压深灰，对比弱。xterm 4.0.0 的调色板第 15 槽取的是 `theme.white`，97 实际画成 `n.text`，`brightWhite` 那一位暂时不起作用。（iteration-03, 2026-09-23）
