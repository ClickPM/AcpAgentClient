### 实现要点

- **`lineDiff` 线性化**（`lib/ui/transcript/diff_card.dart`）：diffutil 的更新从尾到头派发、不带移动，每条的 `position` 都是旧文件的原始下标；一遍登记「删哪几行、哪个下标前插哪几行」，再顺序拼出。与原实现逐行一致（`test/ui/diff_card_test.dart` 保留原实现当对照，2000 组随机输入）。
- **展开体惰性**：转录是一个 ListView、整张 diff 卡是其中一项，卡内要惰性只能自己按滚动位置算窗口——行高固定（画板 21 本来就画的是 mono 12.5 · line-height 1.7，改前实现没跟上），本体占 `行数 × 行高`，只在 Stack 里放视口上下各多一屏的行（32 行对齐）。窗口在两个时机算：外层滚动时当场算（`RenderAbstractViewport.getOffsetToReveal` 求本体在滚动坐标里的位置，不依赖本帧布局）；父级重建后帧尾补算一次（卡被上面的条目挪了位置但没有滚动事件——流式追加、折叠都会重建转录）。外面没有竖向滚动时全建。
- **定位回调**：行 widget 缓存着，转录每次 build 新建的 `onLocate` 闭包经 State 的 `_locate` 转一道，点到的永远是最新那一个。
- **Markdown 安全块边界**（`lib/ui/transcript/markdown_body.dart` 的 `markdownSafeBoundary` / `MarkdownStream`）：在「空行之后、下一块首行收全、不在围栏里、首行顶格且不是列表标记也不以 `<` 开头」处切开，前后分别解析与整段解析的顶层块一致；有链接引用 / 脚注定义（全文级）或 `\r` 换行时整段解析（与改前同）。按 package:markdown 的实现逐条核过：列表只在「空行后跟顶格非列表行」时结束；引用、表格、段落、缩进代码块遇空行结束；`HtmlBlockSyntax` 给不是全文第一块的 HTML 块前补一个换行（等价性测试逐字符喂时抓出来的），所以 `<` 开头的行不当切点。
- **围栏跟踪要与解析器逐条一致**（第 1 轮审查 high 之后）：围栏行按 package:markdown 的 `codeFencePattern` 整行判、收栏信息串 `trim()` 判空；只跟踪顶格的围栏（顶格围栏行一定在顶层：它打断列表、引用、段落、表格）。缩进 1–3 格的围栏行（可能在列表项里，项结束时被隐式收掉）与 `<` 开头的行（HTML 块：第 1–5 类跨空行，第 6 / 7 类块里的 ``` 是原文）一出现就不再往后切——这两种这边不去模拟，宁可少切。
- **封口块复用**：封口的块 widget 实例留在 State，父级每帧给新 `data` 时只重建尾部；recognizer 分 `_stableLinks` / `_tailLinks` 两份，尾部重建只释放尾部那份。换字体 / 主题、改 `onLink` 等参数、输入不再以封口原文开头（改写）时整段重来。
- **代码块高亮缓存**（`lib/ui/transcript/code_block.dart`）：按 (code, language, `Fonts.generation`) 缓存 `TextSpan`。封口的代码块压根不重建；还在尾部、代码没变的（围栏已收、下一段还在写）命中缓存。

### 残留（不在本迭代做）

- 单个超大代码块**自己在流式输出**时，这一块每帧仍是 O(块长)：围栏没收之前它总在尾部，高亮与排版都整块重来（417 行 Dart 高亮 18 ms / JIT）。`re_highlight` 不公开续高亮（`continuation` 是私有的），要做只能按行启发式分段高亮 + 分块排版，属新机制；等实测真撞上再议。
- 很长的列表（整段回答就是一个上百项、项间有空行的列表）封不了口，列表整段都在尾部——判据 3 为了不把松散列表切成两个，宁可不切。
